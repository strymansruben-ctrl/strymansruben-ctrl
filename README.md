# Ruben Strymans

I'm a student in Belgium learning aerospace engineering and software by building small tools. I got interested in propulsion and satellite systems through independent research on SpaceX. I use code to see how far I can get from first principles and where I need better data.

## Projects

| Project | What you can try |
| --- | --- |
| [Launch Staging Lab](https://github.com/strymansruben-ctrl/launch-staging-lab) | Change the payload on a two-stage rocket and see how much ideal delta-v each stage contributes. |
| [Telemetry Replay](https://github.com/strymansruben-ctrl/telemetry-replay) | Feed in a timestamped sensor log and find out when readings cross a limit or samples go missing. |

Both repositories include sample inputs, runnable commands, tests and model limits.
